# Operation First Deploy

A military-themed first Next.js app (App Router + TypeScript).

**Developer:** Christian G. Babatuan
**Course:** BSIT-3, Section 2
**Assignment:** Midterm, Assignment 2: Your First Next.js App

## Run the mission

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.

## Production build

```bash
npm run build
```

The build output shows `○ /` marked `(Static) prerendered as static content`, meaning the home page is generated as static HTML (SSG).

## Files

- `app/page.tsx`: the home page (Server Component) with the developer name
- `app/layout.tsx`: root layout and page metadata
- `app/globals.css`: olive and khaki military styling
- `ANSWERS.md`: written answers for the assignment (View Page Source comparison)
